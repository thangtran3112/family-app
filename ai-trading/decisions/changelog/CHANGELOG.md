# Changelog

One line per shipped phase. Session-level detail lives in the matching handoff (`../plans/handoffs/`); design detail in the ADR it proved.

- **Day list ladder weekdays and earnings state (2026-11-01):** the block ladder labels every day with its weekday (`plan.weekdays`, "Day 3 · Thu"; a day the plan does not list keeps its number alone), and a day-list name carries `earnings_state` (`reported`, `none` when its report history was read and holds none, null when not checked) in place of the positive-only `reported_before_open`: the Earnings column reads the reporting word, "None", or a dash for a name that was not checked (D-018 closed). No migration. Branch `feature/d018-tail`.
- **Improvement week table (2026-11-01):** the Journal's Improvement drawer shows the WEEK 1 / LATEST table (Day results, Win rate, Adherence, Days practiced) only once the first and the latest week each have a practice day; one week alone shows the SIMULATED pill and the caveat naming its real practice-day count and the "3 or more practice days each" threshold; a cell with no data reads as a dash; D-041 Fixed. Branch `feature/d041-pill`.
- **Practice has no guidance bias (2026-11-02):** the thread clock runs on the exchange close (16:00 ET), not the plan's window end; the close rolls the day over with no prompt; a crossed stop is flagged and no longer pauses time; the plan's window end is a "Focus until" mark drawn on the timeline and kept as the review's yardstick. [ADR-0018](../adr/ADR-0018-server-thread-clock.md) amendment 2026-11-02.
- **Practice replay layout (2026-11-01):** a chart carries no Portfolio (it is the Portfolio tab's: the 1440 left-rail block and the 1180 drawer tab are gone, and a name opens from its Portfolio row); the left rail is the technical indicators on top and the Tape below them (the tape leaves the right rail and its 1180 drawer tab); the right rail is the order ticket, its position and Signals, with the vertical room the tape used to take. Frontend only. Branch `feature/fix-replay-layout`.
- **Day list at the clock (2026-11-01):** the Day list's candidate table is read at the thread clock (`GET /day-lists/{id}?live=true`, a `live` block per name cut at the clock, nothing later): "Price now" and the moving metric columns ("… now") follow the clock, the list-time columns say they are fixed; End day and Skip day are on the Summary only ([ADR-0018](../adr/ADR-0018-server-thread-clock.md) amendment). Branch `feature/fix-daylist-pricing`.
- **Practice partial defects, data (2026-11-01):** the day list's Prev RVOL and Prev change % come from the server for every list (`prev_rvol`, `prev_change_pct`, D-018); a thread has its own stored name ("Day thread · Oct 15", "(2)" when taken) and an optional entry size that its tickets open at, shown as Shares in the plan recap (D-042, D-069); migration `0020` (parent `0019`, one revision). Branch `feature/partials-data`.
- **Immersive broker presentation (2026-11-01):** the practice route reads as a neutral broker terminal: no guided chart marks, number-only levels with hover meaning, click-price-to-order, the broker positions list, the list-only day view, progress+repopulate re-scan, the Peek drawer, no keyboard shortcuts, the technical indicators in the replay left rail, and no Back/End-day bar on a day chart. [ADR-0020](../adr/ADR-0020-immersive-broker-presentation.md)
- **Practice replay left rail (2026-11-01):** the replay workspace's left rail is the popular technical indicators (RSI 14, MACD 12/26/9 with signal and histogram, VWAP, EMA 9, EMA 21, each with a word for what it says) computed in the browser from the bars the server has revealed, never from the live Technicals endpoint, so nothing looks ahead; the Session, Plan, Armed-strategies and Signals blocks leave the left rail (Signals moves to the right rail; the 1440 Portfolio stays under the indicators); a day thread's chart loses the Back to the day list link and the End day bar (the tab strip leads back, the Day list ends the day; a swing day and a standalone session keep their one End control because nothing else can end them); Practice has no keyboard shortcuts (no key map, no legend, no `?` overlay; Escape still leaves full screen), so mark undo (⌘Z) is gone from the UI.
- **Away orders fill (2026-11-01):** a limit, stop or stop-limit order that the thread's clock reaches while she is on another name or logged out now fills at its bar (booked when the name is lifted to the clock or the day ends) instead of being cancelled; an order the clock never reached is still cancelled at the day's end. Branch `feature/practice-clock-fills`. [ADR-0019](../adr/ADR-0019-away-orders-fill.md)
